# ADR-008: Визуальный язык и моушен — «Linguist's Atlas»

## Status
Accepted

## Date
2026-10-01

## Context
«Вау»-графика — важная часть продукта. Текущая тема (`#f4f1ea` крем + терракота
`#c2410c`) — это ровно тот «сгенерированный по умолчанию» вид (тёплый крем +
серифный дисплей + глиняный акцент), которого просят избегать. Нужен отличимый,
узнаваемый язык, который одновременно вызывает доверие у лингвистов и работает
с темами MUI light/dark.

## Decision
Принять направление **«Linguist's Atlas»** — учёная картография + звёздная карта.

**Палитра (древние пигменты, семантическая, минимум цветов):**
- `ink` — текст/стволы: light `#1C1A17`, dark `#EDE7DA` (тёплый почти-чёрный, не `#111`).
- `ultramarine` — **общий предок / PIE** (самое глубокое синее): light `#2B4C9B`, dark `#6F8FF5`.
- `gold` — единственный «вау»-сигнал (рябь, подчёркивание): `#C8912A` / `#F2C14E`. Только на моменте предка.
- `verdigris` — заимствование / ареальный контакт: `#2F7E76` / `#5FC7BC`.
- `proto/uncertain` — нейтральный `text.secondary` с пониженной непрозрачностью (реконструкция должна выглядеть *тихо*).
- Фоны: пергамент `#F2ECDE` / бумага `#FCF8F0` (light), `#12110F` / `#1C1A17` (dark).

**Правило иерархии — формой/размером/непрозрачностью, не числом оттенков.** Цвет несёт
ровно три смысла: живое слово, общий предок, «вау».

**Типографика:** реконструированные формы (`*…`) — курсивный **сериф** (Newsreader /
Source Serif 4, woff2, `font-display: swap`); аттестированные слова — UI-без.
Ларингалы (`h₁ h₂ h₃`) — через `<sub>`/`<tspan baseline-shift="sub">`, не через
`font-feature-settings`. Астериск — семантический знак «неаттестировано», а не пунктуация.

**Узлы — по возрасту/уровню (форма):** PIE — крупное полое кольцо (пунктир, если
реконструкция); промежуточные прото — среднее кольцо (пунктир если реконструкция);
аттестированные — залитый диск; четыре языка приложения — диск + ореол; вымершие (†) — контур.

**Линии — по отношению (из `EtymologyNode.relation`):** наследование — сплошная;
реконструкция/неуверенность — пунктир; заимствование — точечная с головкой.

**Моушен (токены):**
- Длительности: 120 / 200 / 280 / 420 / 640 / 900 ms (max для одного элемента).
- Кривые: enter `cubic-bezier(.16,1,.30,1)`, exit `(.40,0,1,1)`, move `(.20,0,0,1)`, emphasis `(.34,1.56,.64,1)`, draw `(.33,0,.15,1)`.
- Стаггер: узел 80 ms, ветвь 120 ms; суммарно ≤ 1200 ms.
- Смысл: **рост = из истока в настоящее** (ПИЕ-корни внизу → современные слова-крона сверху; обновлено 2026-10-01, путь A); глубина = расстояние, длительность, спокойнее цвет; схождение = две ветви встречаются в один момент, одна рябь; **отсутствие родства анимируется честно** (ветви тянутся и останавливаются с пунктирным зазором).
- Ничего не анимируется в простое; только `transform`/`opacity`/`stroke-dashoffset`.

**Темизация = `mode (light|dark) × skin (atlas | constellation | plate)`** через
ремап токенов (`createTheme` + `data-skin` + CSS-переменные), **без форка компонентов**.
Базовый — `atlas`; `constellation` (неон, для созвездия/шара/первого показа) и
`plate` (letterpress, для шаринга/печати) — позже как опции.

## Alternatives Considered
- **Neon Constellation** (near-black + светящиеся узлы) — максимум вау и идеально для
  скриншотов, но ниже учёное доверие, риск по контрасту/моушен-сикнесс; light-режим неестественен.
  Оставляем как опциональный скин.
- **Paper & Ink Lineage** (леттерпресс, чёрное+красное) — вне времени и печатно, но минимум
  экранного вау. Оставляем как скин для шаринга.

## Consequences
- Нужно переписать палитру `theme.ts` и выровнять `theme.transitions` (120/200/280).
- Добавить один серифный woff2 и `await document.fonts.ready` перед экспортом в canvas.
- Глобально включить `prefers-reduced-motion` + ручной переключатель.
- Сначала строим моменты M2+M3 (и M1), затем M6 (плита шаринга), затем M5 (атлас).
