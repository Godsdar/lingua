# ADR-005: Дистрибуция без платной подписи на старте

## Status
Accepted

## Context
Подпись/нотаризация macOS стоит $99/год, сертификат Windows — тоже. Платить
до подтверждения спроса нерационально. Нужны бесплатные каналы с низким трением.

## Decision
Ставить на **веб (PWA) и расширение** как основные каналы (Chrome $5 разово,
Firefox/Edge бесплатно), Linux — AppImage (без подписи), Windows — неподписанный
`.exe` (SmartScreen «Run anyway»), macOS — неподписанный билд с инструкцией
обхода Gatekeeper. Подпись macOS добавить после первых денег/аудитории.

## Alternatives Considered
- **Сразу платить $99** — отклонено: нет бюджета и подтверждённого спроса.
- **Только веб** — не покрывает «настольную» ценность и офлайн.

## Consequences
- Плюс: нулевые затраты, максимальный охват веб/расширения.
- Минус: неподписанный macOS требует ручного обхода карантина (инструкция в README).
- Триггер для пересмотра: первые ~$99 дохода или заметный спрос на десктоп.
