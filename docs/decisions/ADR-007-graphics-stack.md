# ADR-007: Графический стек — D3-layout + React-SVG + Motion

## Status
Accepted

## Date
2026-10-01

## Context
Этимологическое древо — текстовая визуализация (язык + реконструированная форма
с диакритикой: `*wódr̥`, `*méh₂tēr`), 10–200 узлов. Нужны: плавные анимации
(«вау»), интерактивность (hover/выбор/pan-zoom), экспорт PNG без сервера,
доступность, и всё это — в трёх средах, включая **popup расширения MV3** с
жёстким бюджетом бандла. Позже — сетевой граф когнатов (сотни–тысячи узлов).
Пользователь просил готовую библиотеку или PixiJS, либо выбор агентов.

## Decision
- **Раскладка:** `d3-hierarchy` (tree/cluster).
- **Рендер:** собственный **SVG, управляемый React** (`<text>`/`<tspan>`, реальные шрифты, `role="tree"`).
- **Pan/zoom:** `d3-zoom`, применяемый императивно к `<g>` (без setState на каждом тике).
- **Анимация:** `motion` (ex-Framer Motion) — `pathLength` (рисование линий), spring-появление узлов, авто-поддержка `prefers-reduced-motion`.
- **Реконструкции:** `<tspan baseline-shift="sub">`/`<sub>` для ларингалов; курсивный серифный шрифт для `*…`.
- **Экспорт PNG:** `modern-screenshot` (SVG/DOM → PNG, без сервера; предварительно `await document.fonts.ready`).
- **Будущая сеть когнатов:** рендер-агностичная модель + ленивая загрузка отдельного рендерера: `@xyflow/react` (≤ ~1–2k узлов) или `Sigma.js + graphology` (WebGL, 10k+). Тяжёлые рендереры **никогда** не попадают в бандл popup.

## Alternatives Considered
- **PixiJS** — нет раскладки, слабая типографика (атласы рвут комбинируемые знаки), нет
  `role`/`tree`, ~255 KB (≈13×), а для ≤200 текстовых узлов это overkill. Отклонён для древа.
- **Apache ECharts** — красив из коробки, но ~359 KB и мало контроля над кастомным видом. Отклонён для MVP.
- **@xyflow/react (React Flow v12)** — сильный runner-up: готовый viewport/minimap/a11y и HTML-узлы
  (лучший перенос строк), но +58 KB и «flowchart»-вид по умолчанию. Держим для будущей сети.
- **Konva / canvas 2D** — хуже с текстом и доступностью; **Three.js** — избыточно; **Cytoscape** — canvas-акцент.
- **react-d3-tree** — быстрый путь, но ограничивает кастомизацию, из которой и рождается «вау».

## Consequences
- Плюс: пиксель-перфект текст и диакритика, настоящая доступность, векторная резкость, дешёвый экспорт PNG.
- Плюс: инкрементальная миграция — модель `{nodes, links}` отделяет раскладку от рендера; текущий `EtymologyGraph` заменяется поэтапно.
- Минус: раскладка и примитивы — на нас (но именно там и рождается визуальная ценность).
- Бандл: +~20 KB (d3) + ~35–46 KB (Motion), приемлемо.

## Priority (порядок работ)
1. SVG-рендерер + движок рисования → моменты **M2+M3** (светящийся путь и схождение ветвей) и **M1** (кинематографичный первый показ).
2. **M6** — «плита» шаринга (sharePlate).
3. **M5** — апгрейд `LanguageTree` в «атлас».
4. **M7** — микроинтеракции.
5. **M4** — «созвездие когнатов» (нужна модель `CognateEdge` в `core/`).
