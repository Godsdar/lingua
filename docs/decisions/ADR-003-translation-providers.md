# ADR-003: Переводы — Wiktionary первично, MyMemory по умолчанию, DeepL/LibreTranslate опционально

## Status
Accepted (supersedes: использование неофициального Google Translate)

## Date
2026-10-01

## Context
Пословные глоссы нужны для поиска целевого слова и построения общего древа.
Ранее использовался неофициальный `translate.googleapis.com`, что неприемлемо
для публичного продукта (ToS/блокировки). MyMemory — официальный, но качество
пословных переводов низкое (`mother → mother`).

## Decision
- **Пословный перевод:** первично — таблицы переводов Wiktionary
  (`{{tt+|ru|вода}}`, в т.ч. подстраницы `word/translations`, пакетно).
- **Fallback:** MyMemory (официальный публичный API).
- **Продакшен-качество:** DeepL (`DEEPL_API_KEY`) или LibreTranslate
  (`LIBRETRANSLATE_URL`) — через env, при наличии ключа.
- Неофициальный Google удалён из кода полностью.

## Alternatives Considered
- **Google (неоф.)** — отклонён: ToS, нестабильность.
- **Только MyMemory** — отклонён: неверные/непереведённые слова.
- **Только DeepL** — качественно, но платно; оставлен как опция.

## Consequences
- Плюс: дефолт без ключей и лицензионно чист.
- Плюс: качество растёт просто установкой env-ключа.
- Минус: пословные подстраницы Wiktionary «тяжёлые» → кэш и пакетная загрузка.
