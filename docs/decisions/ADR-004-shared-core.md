# ADR-004: Платформо-независимое ядро в `src/core/`

## Status
Accepted

## Date
2026-10-01

## Context
Одна и та же логика (этимология, перевод, разбор) нужна десктопу, браузерному
расширению и будущей веб-версии. Дублировать парсинг Wiktionary — путь к
расхождению поведения и двойной поддержке.

## Decision
Вынести всю логику в `src/core/`, используя только стандартные веб-API
(`fetch`, `URLSearchParams`, `AbortController`). Поверхности — тонкие адаптеры:
Electron (main + IPC), расширение (прямой вызов), веб (прямой вызов).
Для CORS в браузере добавлен `origin=*` к запросам Wiktionary; env читается
безопасно (`typeof process !== 'undefined'`).

## Alternatives Considered
- **Общий npm-пакет** — избыточно на текущем масштабе (монорепа не нужна).
- **Копирование кода** — отклонено: рассинхрон.

## Consequences
- Плюс: одна точка правды; новая поверхность ≈ бесплатна.
- Плюс: ядро тестируется в Node без Electron.
- Минус: код ядра обязан оставаться браузеро-совместимым (без Node-API).
