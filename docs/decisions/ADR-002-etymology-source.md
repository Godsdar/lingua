# ADR-002: Источник этимологии — English Wiktionary

## Status
Accepted

## Date
2026-10-01

## Context
Нужна этимология (линия происхождения) слов en/ru/es/fr без API-ключей,
с лицензионной чистотой. Английская Викисловарь содержит структурированные
шаблоны `{{inh|der|bor}}` и отрендеренное `data-ety-tree-json`.

## Decision
Использовать **en.wiktionary.org** как единственный канон:
1. пакетный `action=query&prop=revisions&rvslots=main` для wikitext всех слов;
2. разбор секции языка → POS + шаблоны родства (первый абзац Etymology);
3. fallback на `action=parse&prop=text` + `data-ety-tree-json`, если цепочка
   пуста или не доходит до прото-языка (`*-pro`);
4. общий предок = самый древний совпадающий `(lang, нормализованная форма)`.

## Alternatives Considered
- **Нативные Викисловари (ru/es/fr)** — менее машинно-пригодные шаблоны, разные PIE-реконструкции.
- **Коммерческие этимологические API** — платно, ключи, лицензии.
- **Собственный датасет** — не масштабируется и нечестен по объёму.

## Consequences
- Плюс: бесплатно, CC BY-SA, единый формат шаблонов.
- Минус: зависимость от доступности Wikimedia; троттлинг и ретрай 429 обязательны.
- Обязательство: атрибуция «Wiktionary, CC BY-SA» в UI.
