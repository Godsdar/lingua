# ADR-009: Бэкенд — нет сейчас; тонкий прокси и предвычисленный датасет позже

## Status
Accepted

## Date
2026-10-01

## Context
Веб, десктоп и расширение работают клиентски: веб — статика, запросы к Wiktionary
(CC BY-SA) и MyMemory идут прямо из браузера. Появился вопрос: нужен ли сервер.
Потенциальные причины для бэкенда: скрыть ключи платных провайдеров, кэш,
обход per-IP лимитов, будущие аккаунты/синк, SEO-пререндер, публичный API, а
также «моат» из нормализованного графа когнатов.

## Decision
- **Сейчас бэкенд не нужен.** Для скоупа «одно слово → 2D-дерево» достаточно
  клиентских запросов. Это $0 и максимум приватности.
- **Шов для будущего:** `window.lingua` (браузерный адаптер ядра). Позже
  подменяется на remote-адаптер без переписывания UI.
- **Прокси — только по триггеру:** когда понадобится платный/лучший перевод для
  всех (DeepL) или серверный кэш/обход лимитов. Реализация — тонкая serverless-функция
  (Cloudflare Workers, free tier 100k запросов/день), ключи в env.
- **Никогда не шипить ключи провайдеров в web/extension** — клиент публичен.
  Десктоп может брать ключ из env пользователя.
- **Долгосрочный «бэкенд» — предвычисленный датасет.** На этапе сборки
  генерируем нормализованный этимологический граф и раздаём статически с CDN
  (без сервера): скорость, офлайн, детерминизм, меньше зависимости от Wiktionary.
  Это же — заявленный «моат» в [POSITIONING.md](../POSITIONING.md).

## Alternatives Considered
- **Полный бэкенд (аккаунты, БД, синк) сейчас** — отклонено: стоимость, приватность,
  вне текущего скоупа (ADR-006 — локально, без аккаунта).
- **Ключи провайдеров в клиенте** — отклонено: утечка секретов.
- **Self-host LibreTranslate (VPS ~$5/мес)** — отложено, пока хватает MyMemory.

## Consequences
- Сейчас: $0, без сервера, всё локально.
- Триггеры для прокси: (a) DeepL/платный перевод для всех, (b) превышение лимитов,
  (c) серверный кэш ради скорости.
- Триггер для датасета: SEO-страницы и/или потребность в мгновенном/офлайн-древе.
- Правило безопасности: провайдерские ключи не попадают в клиентские бандлы.
