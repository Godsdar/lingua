# Этимологическое дерево — исследование и мозговой штурм

Статус: черновик · Версия 0.1 · Обновлено: 2026-10-01
Источник: свод трёх исследований (prior art, ботанико-семантический дизайн,
техническая реализуемость). Связано: [ETYMOLOGY_TREE.md](ETYMOLOGY_TREE.md),
[GRAPHICS.md](GRAPHICS.md), [ADR-007](decisions/ADR-007-graphics-stack.md),
[ADR-008](decisions/ADR-008-visual-language.md).

> Проблема: текущий рендер — схематичный node-link (кружки + подписи).
> Цель: **настоящее дерево** с листьями и кроной, но не потеряв лингвистический смысл.

---

## 1. Почему текущий рендер не дерево

- Нет ствола и веток — есть точки и тонкие отрезки.
- Нет листьев и кроны — только подписи.
- Симметрия и прямые сегменты читаются как орг-схема, а не как растение.
- Данные дают **Y-образную структуру** (один ствол → развилка → две цепочки → два листа),
  а не пышную крону; «пышность» придётся добавлять честно (см. §4).

## 2. Ключевая развилка: ориентация (нужно решение)

| | A. ПИЕ внизу (корни), слова сверху (крона) | B. Текущее: ПИЕ сверху | C. Кольца роста (радиальное) |
|---|---|---|---|
| Время | низ→верх = древнее→современное | верх→низ | центр→край |
| Ощущение | родословная как корни, слова «расцветают» | орг-схема/канделябр | кабинетный экспонат, спил |
| Похоже на дерево | **10/10** | 3–4/10 | 6/10 (дерево), 9/10 (организм) |
| Конфликт | правки GRAPHICS §4.1 («подъём = в прошлое») | совпадает с текущими доками | вне обоих |
| Бонус честности | под землёй = реконструкции (их не видно напрямую) | — | кольца = буквальный возраст |

**Рекомендация агентов:** **A** для интерактивного дерева (рост = из истока в
настоящее; «aha» вспыхивает под землёй, в корне), **C** — как скин карточки-шаринга.

✅ **Решено (2026-10-01): идём по пути A** — ПИЕ внизу (корни), современные слова
сверху (крона), рост из истока в настоящее. Это правка прежнего «корень сверху»
(ETYMOLOGY_TREE §1) и правила GRAPHICS §4.1; ADR-008 обновлён. Реализовано:
развёрнутая ось, корневой наплыв, земля, рост вверх.

## 3. Ботанико-лингвистическая карта (что чему соответствует)

| Ботаника | Лингвистика | Честно? |
|---|---|---|
| Корни (под землёй) | глубочайший ПИЕ-этимон | ✅ + реконструкция «не видна» |
| Корневая шейка/развилка | общий предок (`isDivergence`) — **золотая вспышка** | ✅ |
| Ствол | общая линия (ПИЕ→развилка) | ✅ |
| Ветви/сучья | промежуточные прото/старые формы | ✅ |
| Толщина ветви | ОДНА метрика: число потомков ИЛИ возраст | ⚠️ не смешивать |
| Длина ветви | прошедшее время (если есть даты) | ✅, иначе декор |
| Годовые кольца | эпохи/глубина | ✅✅ |
| Кора (текстура) | достоверность: гладкая = аттестовано, штриховая = `*` | ✅ |
| Листья | современные аттестированные слова (источник + перевод) | ✅ |
| Крона (силуэт) | охват семьи | ⚠️ при 2 листьях — атмосфера |
| Плоды/цветы | производные/когнаты (позже) | ✅ когда есть данные |
| Прививка | заимствование (verdigris) | ✅ |
| Опавшие листья | вымершее (†)/ложные друзья | ✅ если оторваны и в легенде |

**Никогда не кодировать цветом смысл, числом листьев — частотность, пышностью — размер семьи.**

## 4. Два листа → как сделать дерево (и где граница обмана)

По силе эффекта:
1. **Один непрерывный сужающийся изогнутый ствол** + корневой наплыв — рисовать
   как заполненный контур, а не как набор прямых отрезков.
2. **Крона через space colonization** (200–600 аттракторов) — декоративные веточки.
3. **Две ветви с вторичными сучками** (на сучок — реальная промежуточная форма).
4. **Кластер листьев на каждое современное слово** (5–9 листьев; один крупный =
   само слово, остальные — его «пучок»; одно слово = один пучок → честно).
5. **Декоративные микро-листья** в кроне (≤35% непрозрачности, без подписей).
6. **Силуэт кроны** — мягкий безье-контур.
7. **Линия земли + слои почвы** — привязка корней.
8. **Асимметрия, гравитация (провисание), лёгкий наклон.**
9. **Тень/световое пятно** — якорь в пространстве.
10. **Лёгкое покачивание в простое** (≤1.5°, выкл. при reduced-motion).

**Граница честности:** декор не должен (а) заканчиваться в подписанном узле,
(б) совпадать по размеру/форме/контрасту с настоящим листом, (в) быть счётным до
«значащего» числа. Добавить **тумблер «голые ветви»** — если без листвы всё ещё
читается как дерево, листва честная; если схлопывается в палку — это была иллюзия.

## 5. Алгоритмы раскладки и роста

| Алгоритм | Для чего | Когда |
|---|---|---|
| Рекурсивное ветвление + джиттер + гравитация | органичные веточки кроны | всегда (декор) |
| **Space colonization** (Runions 2007) | светоищущий объём кроны | главный рычаг «дерева» |
| L-system | детерминированный каркас | только фон/декор |
| Радиальная ботаническая раскладка | полярная ось времени | концепт C / шара |
| Bonsai-кривизна | Catmull-Rom + шум | поверх всего |

**Как не потерять семантику:** `d3.hierarchy` остаётся источником правды;
декор-веточки не становятся узлами. Каждому ребёнку — **угловой сектор**
(source — влево, target — вправо, ствол — по оси), направление ветвей
зажимается в сектор → линии не перепутываются. Позиции — из `tree().nodeSize`;
затем лёгкая force-релаксация (пружины к исходным координатам + коллизии +
гравитация), заморозка после N тиков. Подписи крепить к **параметру t на кривой**,
а не к точкам.

## 6. Prior art и готовые решения

**Главный вывод:** готового «этимологического дерева» нет — Etymonline/Wiktionary
это текст/JSON, Visuwords — граф. Красоту придётся собирать самим из геометрии
филогенетики + органики процедурной ботаники.

Ранжированные ориентиры:
1. **Minna Sundberg, дерево языков** — https://sssscomic.com/comic2.php?page=160 —
   буквально «дерево семей языков»: ствол, крона, подписи вдоль ветвей. Ближайший арт-референс.
2. **OneZoom** — https://www.onezoom.org/ (repo https://github.com/OneZoom/OZtree) —
   лучший интерактивный «реальный» дерево-браузер (фрактальные сужающиеся ветви, зум). Лицензия своя — копировать идеи, не код.
3. **Space Colonization (Runions et al. 2007)** —
   https://algorithmicbotany.org/papers/colonization.egwnp2007.html +
   формула сужения из https://github.com/dsforza96/tree-gen — как получить органичный каркас.
4. **The Word Tree (Wattenberg & Viégas, 2008)** — https://www.jasondavies.com/wordtree/ —
   «общий префикс → общая ветвь» = твой общий предок; лучший референс по читаемости текста в дереве.
5. **D3 hierarchy gallery** — радиальное дерево https://observablehq.com/@d3/radial-tidy-tree,
   Tree of Life https://observablehq.com/@d3/tree-of-life, collapsible https://observablehq.com/@d3/collapsible-tree.

Готовое к адаптации (стек):
- **Оставить** `d3-hierarchy` (ISC) для раскладки; `d3-shape` (`curveBumpX`) для безье.
- **Форкнуть `react-d3-tree`** (MIT, https://github.com/bkrem/react-d3-tree) — уже даёт
  React+SVG+zoom+collapse+custom node; заменить один path на сужающийся и добавить слой листвы.
- Или **`@visx/hierarchy`** (MIT, https://airbnb.io/visx/docs/hierarchy) — если хотим владеть
  всей геометрией с нуля.
- Органичный каркас — портировать **space colonization** (минимальные реализации:
  https://github.com/panahiparham/2d_tree_generation, https://github.com/dsforza96/tree-gen,
  детерминированный рост: https://github.com/w3labkr/js-growing-tree).
- **Не брать:** OneZoom (лицензия), iTOL (сервис), ECharts tree (canvas, схематично), Cytoscape/Sigma (граф).
- Арт-референсы: Haeckel «Tree of Life» (PD), Tree of Life от Kurzgesagt, Stefanie Posavec.

## 7. Технический рецепт (наш стек)

- **Ствол/ветви:** не `stroke` одинаковой ширины, а **сужающиеся** — либо нарезка
  кубика на K≈6 сегментов со `strokeWidth` от w0→w1 и круглыми концами, либо
  настоящая лента (offsets по нормали, заполненный `path`). Толщина `w(depth)=W0·0.6^depth`.
- **Изгиб/гравитация:** кубик с провисанием вниз и лёгким боковым бендом; цепочки —
  Catmull-Rom для C1-непрерывности (убрать «изломы» на узлах).
- **Листья:** форма-миндаль в `<defs>`, `use`; кластер 3–7 листьев у терминала;
  анимация раскрытия spring с `transformOrigin: 0% 50%` (иначе «качаются из ниоткуда»).
- **Анимация роста (motion):** `pathLength` для ветвей, delay = `depth·0.12s`; листья —
  `scale/rotate` spring; `useReducedMotion()` → финальный кадр.
- **Детерминизм:** сид из `fnv1a(lang|word)` → `mulberry32`; отдельные потоки для ветвей
  и листвы. Никогда `Math.random`/`Date.now` — иначе дерево «дрожит» между рендерами.
- **Читаемость:** подписи в «коридоре», halo через `paint-order: stroke fill`; листва
  позади текста и ≤35% непрозрачности; кегль ≥12–13px; LOD (скрывать подписи при зуме <0.8).
- **A11y (обязательно):** листва `aria-hidden`; параллельно рендерить **настоящий
  вложенный список** (`role=tree`/`treeitem`), где SVG — проекция, а список — истина.
- **Пределы SVG:** сотни листьев ок; тысячи анимированных — нет (тогда canvas; в popup — никогда).
- **PNG-экспорт:** `await document.fonts.ready`; self-host шрифтов; тест прозрачности.

## 8. Три концепции

**1. «Укоренённый свидетель» (рекомендация).** ПИЕ — корни внизу, слова — крона сверху;
две линии поднимаются и встречаются в корне-предке, золотая вспышка под землёй.
Максимально «дерево», честно. Требует разворота оси (правка GRAPHICS §4.1).

**2. «Висящая ветвь» (текущая ориентация).** Древнее — сверху как «крона истоков»,
современные слова висят внизу плодами. Не конфликтует с доками, но читается как канделябр.
```
═══ *ПИЕ* ═══════════════════════
     \  |  /    ранние расколы
      \ | /
       ||| больше не вертикально чисто
      / | \
  @ @ (A)   (B) @ @
```

**3. «Кольцо роста» (скин шаринга).** Спил: каждое кольцо — эпоха, слова на ободе.
```
        word₂
          @
    ~ ~ ~ ~ ~ ~ ~
  ~   ( ring3 )   ~
~  word₁ (PIE•) @ ~
  ~   ( ring3 )   ~
    ~ ~ ~ ~ ~ ~ ~
          @
```

**Рекомендация:** строить **1**, оставить **3** для карточки-шаринга, не трогать three.js (ADR-007).

## 9. Что важнее всего для «жизни» (приоритет)

1. **Один непрерывный сужающийся изогнутый ствол + наплыв корня** (не набор отрезков).
2. **Крона space colonization** — веточки превращают «линии» в «дерево».
3. **Настоящие формы листьев с прожилкой, пучок на слово** + слабые микро-листья.
4. **Анимация роста + лёгкое покачивание** (motion; выкл. при reduced-motion).
5. **Золотая вспышка сходжения в корне** — единственный акцент, эмоциональная развязка.

## 10. Рекомендуемый первый инкремент

Сохраняя раскладку и компонент, заменить **только** отрисовку рёбер:
1. сужающиеся, с гравитацией, изогнутые ствол/ветви (вместо прямых отрезков);
2. кластер листьев на двух терминальных узлах;
3. halo за подписями (`paint-order`) и подложка под `*`-формами;
4. детерминированный сид `fnv1a(lang|word)`;
5. сохранить current stagger и `useReducedMotion`.

Это даёт заметный «вау, это дерево» без новых зависимостей и без переписывания.
